# RPG_prototype

Survival RPG prototype about a group of survivors. The player acts as a **meta-character of the shelter**—managing the base, choosing NPC squads for expeditions, and living with the consequences—not as a field combat avatar.

This repository is currently **documentation-first**. Implementation has not started; direction and decisions are captured in small work packages before code.

## Documentation
